# AI-Based Production Monitoring System

## Project Overview
AI-Based Production Monitoring System is a web-based application designed to monitor manufacturing operations in real time. The system tracks production performance, machine utilization, downtime, and production targets while providing AI-powered predictions and analytics.

## Features
- Production Data Management
- Machine Monitoring
- Downtime Tracking
- Performance Dashboard
- AI-Based Production Prediction
- Real-Time Analytics

## Technologies
- Python (Flask)
- MySQL
- HTML, CSS, JavaScript
- Chart.js
- Scikit-learn
